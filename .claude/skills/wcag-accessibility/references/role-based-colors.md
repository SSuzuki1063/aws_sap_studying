# 役割別カラーパレット

このドキュメントでは、WCAG 2.1 AA準拠を保証するために、用途別に分類されたカラーパレットを定義します。

## 設計原則

1. **テキストは役割で色を選ぶ** - 見出し/本文/補足で異なる色を使用
2. **背景コンテキストで色を切り替える** - 明るい背景/暗い背景で別の色セット
3. **CSS変数を使用** - 直接色コードを書かない

---

## 明るい背景用テキスト色

白背景（#ffffff）またはライトグレー背景（#f9fafb）で使用。

### テキスト階層

| 役割 | CSS変数 | 色コード | コントラスト比 | 用途例 |
|------|---------|---------|--------------|--------|
| 見出し | `--color-text-heading` | `#1f2937` | 14.68:1 | h1, h2, h3, セクションタイトル |
| 本文 | `--color-text-primary` | `#374151` | 9.86:1 | p, li, 説明文 |
| 補足 | `--color-text-muted` | `#4b5563` | 7.21:1 | サブテキスト、日付 |
| キャプション | `--color-text-secondary` | `#6b7280` | 4.83:1 | 画像キャプション、ヘルパーテキスト |

### 使用例

```css
/* 見出し */
h1, h2, h3 {
    color: var(--color-text-heading, #1f2937);
}

/* 本文 */
p, li {
    color: var(--color-text-primary, #374151);
}

/* 補足テキスト */
.subtitle, .date {
    color: var(--color-text-muted, #4b5563);
}

/* キャプション */
figcaption, .helper-text {
    color: var(--color-text-secondary, #6b7280);
}
```

## 暗い背景用テキスト色

AWS Dark（#232F3E）またはダークグレー（#1F2937）背景で使用。

### テキスト階層

| 役割 | CSS変数 | 色コード | コントラスト比 | 用途例 |
|------|---------|---------|--------------|--------|
| メイン | `--color-text-white` | `#ffffff` | 12.98:1 | 見出し、重要テキスト |
| ミュート | `--color-text-on-dark-muted` | `#e5e7eb` | 10.15:1 | 補足、サブテキスト |

### 使用例

```css
/* 暗い背景のセクション */
.dark-section {
    background: var(--color-aws-dark, #232F3E);
}

.dark-section h2 {
    color: var(--color-text-white, #ffffff);
}

.dark-section p {
    color: var(--color-text-on-dark-muted, #e5e7eb);
}
```

## 背景コンテキスト別の使い分け

### 決定フローチャート

```
背景色を確認
    │
    ├─ 明るい背景 (輝度 >= 0.5)
    │   └─ 明るい背景用テキスト色を使用
    │       ├─ 見出し → #1f2937
    │       ├─ 本文 → #374151
    │       ├─ 補足 → #4b5563
    │       └─ キャプション → #6b7280
    │
    └─ 暗い背景 (輝度 < 0.5)
        └─ 暗い背景用テキスト色を使用
            ├─ メイン → #ffffff
            └─ ミュート → #e5e7eb
```

### 主な背景色と対応テキスト色

| 背景 | 背景色コード | 輝度 | 推奨テキスト色 |
|------|------------|------|--------------|
| 白 | `#ffffff` | 1.0 | 明るい背景用 |
| ライトグレー | `#f9fafb` | 0.97 | 明るい背景用 |
| カード背景 | `#f3f4f6` | 0.95 | 明るい背景用 |
| ミディアムグレー | `#9ca3af` | 0.42 | 要検証 |
| AWS Dark | `#232F3E` | 0.04 | 暗い背景用 |
| ダークグレー | `#1f2937` | 0.03 | 暗い背景用 |

## カテゴリ別アクセント色

各カテゴリには識別用のアクセント色が割り当てられています。

| カテゴリ | 色コード | コントラスト比 (白背景) | 用途 |
|---------|---------|------------------------|------|
| ネットワーキング | `#2563eb` | 4.56:1 | バッジ、アイコン |
| セキュリティ | `#dc2626` | 4.63:1 | バッジ、アイコン |
| コンピュート | `#d97706` | 3.19:1 | バッジ、アイコン |
| ストレージ | `#059669` | 4.52:1 | バッジ、アイコン |
| 分析 | `#7c3aed` | 5.37:1 | バッジ、アイコン |

**注意**: カテゴリ色は主にバッジやアイコンなどのUI要素に使用し、本文テキストには使用しないでください。

## 禁止パターン

### 使用禁止の色コード

| 色コード | 理由 | 代替色 |
|---------|------|--------|
| `#9ca3af` | コントラスト不足 (3.53:1) | `#6b7280` |
| `#d1d5db` | コントラスト不足 (1.99:1) | `#6b7280` |
| `#FF9900` | 通常テキストでコントラスト不足 | `#dc7600` |

### コード例

```css
/* ❌ 禁止 */
.caption {
    color: #9ca3af;  /* コントラスト不足 */
}

/* ✅ 推奨 */
.caption {
    color: var(--color-text-secondary, #6b7280);
}
```
