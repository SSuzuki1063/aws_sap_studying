# 背景コンテキスト判定ルール

テキスト色の選択は背景コンテキストに依存します。このドキュメントでは、背景の輝度に基づいてテキスト色を選択するルールを定義します。

## 輝度しきい値

### 基本しきい値

| 輝度範囲 | 分類 | 推奨テキスト色 |
|---------|------|--------------|
| 0.8 以上 | 非常に明るい | 暗いテキスト（#1f2937〜#6b7280） |
| 0.5 〜 0.8 | 明るい | 暗いテキスト |
| 0.2 〜 0.5 | 中間 | 個別検証必要 |
| 0.2 未満 | 暗い | 明るいテキスト（#ffffff, #e5e7eb） |

### 輝度の計算

```python
def calculate_luminance(hex_color):
    """HEX色コードから輝度を計算"""
    r = int(hex_color[1:3], 16) / 255
    g = int(hex_color[3:5], 16) / 255
    b = int(hex_color[5:7], 16) / 255

    def linearize(c):
        return c / 12.92 if c <= 0.03928 else ((c + 0.055) / 1.055) ** 2.4

    return 0.2126 * linearize(r) + 0.7152 * linearize(g) + 0.0722 * linearize(b)
```

## リポジトリ内の主要背景色と輝度値

### 明るい背景

| 用途 | 色コード | 輝度 | 推奨テキスト |
|------|---------|------|------------|
| ページ背景 | `#ffffff` | 1.000 | 暗いテキスト |
| セクション背景 | `#f9fafb` | 0.973 | 暗いテキスト |
| カード背景 | `#f3f4f6` | 0.946 | 暗いテキスト |
| ホバー背景 | `#e5e7eb` | 0.865 | 暗いテキスト |

| 用途 | 色コード | 輝度 | 推奨テキスト |

| フッター | `#1f2937` | 0.031 | 明るいテキスト |

| 無効状態 | `#9ca3af` | 0.423 | テキストには使用禁止 |

## グラデーション背景の判定方法

### 線形グラデーション

グラデーションの場合、**最も明るい部分**でコントラストを計算します（最悪ケースの保証）。

```css
/* グラデーション例 */
background: linear-gradient(135deg, #232F3E 0%, #374151 100%);
```

判定：
1. 開始色の輝度: `#232F3E` → 0.037
2. 終了色の輝度: `#374151` → 0.071
3. **最大輝度 0.071** で判定 → 暗い背景 → 明るいテキスト

### 放射状グラデーション

```css
background: radial-gradient(circle, #374151 0%, #232F3E 100%);
```

中心が最も明るいため、中心色（#374151）で判定。

## 半透明オーバーレイの計算方法

### アルファブレンディング

半透明色は下層の色と合成されます。

```
result = overlay_color * alpha + background_color * (1 - alpha)
```

### 計算例

```css
/* 背景画像 + 半透明オーバーレイ */
.hero {
    background-image: url('hero-image.jpg');
    background-color: rgba(0, 0, 0, 0.7);  /* 70%黒オーバーレイ */
}
```

計算（背景画像の最も明るい部分が白の場合）：

1. 背景色: `#ffffff` (RGB: 255, 255, 255)
2. オーバーレイ: `rgba(0, 0, 0, 0.7)`
3. 合成結果:
   - R: 0 * 0.7 + 255 * 0.3 = 76.5
   - G: 0 * 0.7 + 255 * 0.3 = 76.5
   - B: 0 * 0.7 + 255 * 0.3 = 76.5
4. 結果色: `#4d4d4d`（輝度: 0.089）→ 暗い背景

### 推奨オーバーレイ不透明度

| 下層の明るさ | 推奨不透明度 | 結果 |
|-------------|------------|------|
| 明るい画像 | 70%以上 | 暗い背景として扱える |
| 暗い画像 | 50%以上 | 暗い背景として扱える |
| 中間の画像 | 80%以上 | 個別検証推奨 |

## 実装パターン

### パターン1: 背景色を明示的に指定

```css
/* ✅ 推奨: 背景色を明示 */
.card {
    background-color: #ffffff;
    color: #374151;
}

/* ❌ 非推奨: 背景色が不明確 */
.card {
    color: #374151;
}
```

### パターン2: 背景変更時のテキスト色リセット

```css
/* 暗い背景のコンテナ */
.dark-container {
    background: #232F3E;
    color: #ffffff;
}

/* 内部に明るい背景のカードを配置 */
.dark-container .card {
    background: #ffffff;
    color: #374151;  /* ← テキスト色も変更必須 */
}
```

### パターン3: CSS変数による一貫性

```css
:root {
    /* 明るい背景用 */
    --bg-light: #ffffff;
    --text-on-light: #374151;

    /* 暗い背景用 */
    --bg-dark: #232F3E;
    --text-on-dark: #ffffff;
}

.light-section {
    background: var(--bg-light);
    color: var(--text-on-light);
}

.dark-section {
    background: var(--bg-dark);
    color: var(--text-on-dark);
}
```

## 自動検出できないケース

以下のケースは手動確認が必要です：

### 1. 背景画像

```css
.hero {
    background-image: url('hero.jpg');
    color: #ffffff;  /* 画像の明るさに依存 */
}
```

**確認方法**: 画像の最も明るい部分でコントラストを確認

### 2. 動的に変化する背景

```javascript
element.style.backgroundColor = userSelectedColor;
```

**確認方法**: 想定される色範囲でコントラストを確認

### 3. ブラウザ拡張/ユーザースタイル

ユーザーが背景色を変更する可能性を考慮。

**対策**: テキスト色と背景色を常にセットで指定
