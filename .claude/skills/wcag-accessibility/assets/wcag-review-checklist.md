# WCAG 2.1 AA レビューチェックリスト

Yes/No形式のレビューチェックリストです。新規ページ作成時やデプロイ前の最終確認に使用してください。

---

## 使い方

1. 各項目に Yes / No / N/A で回答
2. すべて Yes または N/A になるまで修正
3. No がある場合は対応策を実施してから再確認

---

## 1. カラーコントラスト

| # | チェック項目 | Yes/No/N/A | 備考 |
|---|-------------|-----------|------|
| 1.1 | 通常テキスト（<18pt）のコントラスト比は 4.5:1 以上か？ | | |
| 1.2 | 大きいテキスト（>=18pt）のコントラスト比は 3.0:1 以上か？ | | |
| 1.3 | UIコンポーネント（ボタン枠線、アイコン）のコントラスト比は 3.0:1 以上か？ | | |
| 1.4 | フォーカスインジケーターのコントラスト比は 3.0:1 以上か？ | | |

### 自動検証コマンド

```bash
python3 scripts/accessibility/check_contrast_ratio.py path/to/file.html
```

### よくある問題

- 薄いグレー（#9ca3af, #d1d5db）をテキストに使用 → #6b7280 に変更
- AWS公式オレンジ（#FF9900）を通常テキストに使用 → #dc7600 に変更

```bash

```

### 実装例

```html

  <!-- content -->
</svg>

<!-- 装飾的なSVG -->
<svg aria-hidden="true">
  <!-- decorative content -->
</svg>
```

## 4. キーボード・フォーカス

| # | チェック項目 | Yes/No/N/A | 備考 |
|---|-------------|-----------|------|
| 4.1 | すべてのインタラクティブ要素にTabキーでフォーカスできるか？ | | |
| 4.2 | フォーカス順序は論理的で意味のある順序か？ | | |
| 4.3 | フォーカスインジケーターは視覚的に明確か？ | | |
| 4.4 | キーボードトラップ（フォーカスが抜け出せない状態）がないか？ | | |

### 手動テスト方法

1. ページを開く
2. マウスを使わずにTabキーのみで移動
3. すべてのリンク・ボタン・フォーム要素にフォーカスできることを確認
4. Enter/Spaceキーで要素を操作できることを確認
5. モーダルはEscキーで閉じられることを確認

### よくある問題

- `<div onclick>` を使用 → `<button>` に変更、または `role="button"` と `tabindex="0"` を追加
- `outline: none` でフォーカス表示を削除 → 代替のフォーカススタイルを提供

## 5. 言語・メタ情報

| # | チェック項目 | Yes/No/N/A | 備考 |
|---|-------------|-----------|------|
| 5.1 | `<html lang="ja">` が設定されているか？ | | |
| 5.2 | ページに説明的で一意な `<title>` が設定されているか？ | | |

### 自動検証コマンド

```bash
# lang属性の確認
grep -l '<html[^>]*lang="ja"' path/to/file.html

# title要素の確認
grep '<title>' path/to/file.html
```

### 推奨フォーマット

```html
<title>VPC完全ガイド - ネットワーキング | AWS SAP学習リソース</title>
```
